A Q-value is the network's estimate of the total future reward the agent expects if it takes that action in the current state and then keeps playing well. The agent normally picks the action with the highest Q-value.

Explore vs. Exploit

ε (chance of a random move): 1.00
Explore moves: 0 · Exploit moves: 0

Why random moves? At the start the network knows nothing, so its "best" action is meaningless. Exploration (random actions) lets the agent discover rewards it would never find otherwise. Exploitation uses current knowledge. We start with ε = 1 (all random) and shrink ε toward 0.05 as the agent learns, so it gradually shifts from exploring to exploiting.

This is a real, small Deep Q-Network written in plain JavaScript: a neural network with 7 inputs, 16 hidden ReLU neurons and 3 outputs (LEFT, STAY, RIGHT), trained with a replay buffer, a target network, an ε-greedy policy and back-propagation.

Honesty note: this is a simplified demonstration, not DeepMind's original Atari system. DeepMind used raw screen pixels and a large convolutional network trained on millions of frames. Here the state is just 7 numbers (see panel 2), so it trains in minutes on a laptop. Rewards: +1 per brick, +0.5 for hitting the ball with the paddle, −1 for losing a life, and a tiny shaping penalty (−0.02 × distance) while the ball falls and the paddle is far from it. Nothing is prerecorded; every chart below comes from the live simulation.

Network diagram: cyan lines = positive weights, magenta = negative weights (brighter = larger). Node brightness = current activation. Outputs are the three Q-values.

The learning loop

  1. Observe the state
  2. Select an action (ε-greedy)
  3. Perform the action
  4. Receive a reward
  5. Store the experience & update the network
  6. Repeat

The target for each update is reward + γ · max Q_target(next state) (γ = 0.95). The network is nudged so its Q-value for the action taken moves toward that target. A separate target network, copied from the main one every 500 steps, keeps the target from shifting at every step, which stabilises training.

🕹️ How to play

  • Press ▶ Start game, then use ← and → to move the paddle. Press Pause any time. After game over, press Space to play again.
  • Bounce the ball off the paddle to break bricks. It also bounces off the gray walls.
  • Higher layers score more: top layer 7 points, then 5, 3, and 1 at the bottom.
  • If the ball hits the ground you lose one of your 5 lives, and a new ball is served while lives remain.
  • Goal: the highest score before you run out of lives.

📚 How the AI learns

  1. Look. The agent sees a small picture of the screen (20×24 cells) and the picture from one move earlier, so it can tell where the ball is heading.
  2. Guess. A convolutional neural network turns those pictures into 3 Q-values, one each for Left, Stay, Right. A Q-value is the total reward the agent expects to collect from now on.
  3. Act. It usually picks the best move, but with chance ε it picks a random one. This is how it explores. ε shrinks as it gains experience.
  4. Remember. After each move it stores (state, action, reward, next state) in a memory called the replay buffer. Rewards: points for a brick (top layers pay more), 0 for ordinary moves, −1 for losing a life.
  5. Learn. It picks 32 random memories and nudges the network, using back-propagation, so that its guess moves toward reward + 0.97 × best Q-value of the next state. That target comes from a frozen copy of the network (the target network), refreshed every 1000 steps to keep learning stable.
